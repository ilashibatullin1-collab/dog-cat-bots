# PetShop Stars 🐾

Игровой магазин для Telegram-бота, где пользователи покупают одежду для питомцев за Telegram Stars.  
Проект на **Python** + **aiogram 3.x** + **SQLite**.

## ✨ Особенности проекта

*   **Telegram Stars:** Интеграция оплаты через нативную валюту Telegram.
*   **Инвентарь и коллекции:** Система хранения вещей, сезонные коллекции с датами действия.
*   **Бонусы и рейтинг:** Накопление бонусов для скидок и система рейтинга пользователей.
*   **Админ-панель:** Добавление товаров через команду `/additem`.
